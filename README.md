### Hi, I'm Alex Semeniuk

Platform architect working in .NET. I like architecture that's boring on purpose: predictable to deliver, easy to test, safe to run.

#### Working with coding agents

- **[claude-agents-vm](https://github.com/sovist/claude-agents-vm)**: run several Claude Code agents in sandboxed containers on a Linux VM, and drive them from your own Claude Code via MCP.
- **[agent-loop](https://github.com/sovist/agent-loop)**: a plan-first Architect / Senior Dev / Tech Lead loop for Claude Code. The Architect plans before any code exists and reviews every iteration; each role is a fresh subagent every turn, and every handoff is a file.
- **[agents-can-write-tests](https://github.com/sovist/agents-can-write-tests)**: agents can write tests that mean something, when the cheapest test tells a user story and the expected values come from outside the agent. A runnable .NET example with no mocks, and CI showing where each rule takes over.

#### .NET libraries

- **[resolve-pattern](https://github.com/sovist/resolve-pattern)**: lazy, ambient service resolution for .NET, an alternative to constructor injection for long-lived, graph-shaped applications. It has run in production for about eight years.
- **[EntityFramework-Plus-MIT](https://github.com/sovist/EntityFramework-Plus-MIT)**: an MIT-licensed fork of EF Plus, with batch update and delete rebuilt on EF Core's ExecuteUpdate/ExecuteDelete. [![NuGet downloads](https://img.shields.io/nuget/dt/EntityFrameworkPlus.EFCore.MIT?label=NuGet%20downloads)](https://www.nuget.org/packages/EntityFrameworkPlus.EFCore.MIT)
- **[DijkstraFast](https://github.com/sovist/DijkstraFast)**: Dijkstra and A* shortest-path search for .NET, with no dependencies. On a road map of a million intersections it finds a route about 6x faster than QuikGraph, in a quarter of the memory. [![NuGet downloads](https://img.shields.io/nuget/dt/DijkstraFast?label=NuGet%20downloads)](https://www.nuget.org/packages/DijkstraFast)
- **[Standards.ISO](https://github.com/sovist/Standards.ISO)**: ISO 3166-1 country codes for .NET. [![NuGet downloads](https://img.shields.io/nuget/dt/Standards.ISO3166.CountryCodes?label=NuGet%20downloads)](https://www.nuget.org/packages/Standards.ISO3166.CountryCodes)
